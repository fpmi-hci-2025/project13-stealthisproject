# Railway Ticket System Documentation

Welcome to the documentation for the Railway Ticket System project for the Minsk Railway Station. This project was developed as part of the "Human-Computer Interface Design" course at BSU.

## Project Overview

The system is a comprehensive solution for purchasing electronic railway tickets, featuring a web application, a mobile application, and a backend API.

## Laboratory Works

This documentation is organized by laboratory work, covering the entire development lifecycle:

*   **[Lab 1: Analysis & Research](lab1/lab1_report.md)** - User research, competitor analysis, and business process modeling.
*   **[Lab 2: Interaction Design](lab2/13_execution_report.md)** - Design strategy, information architecture, and interactive mockups.
*   **[Lab 3: System Architecture](lab3/README.md)** - UML diagrams, C4 model, and EventStorming.
*   **[Lab 4: REST API Modeling](lab4/01_requirements_model.md)** - Database design and API route specification.
*   **[Lab 5: Prototyping](lab5/README.md)** - Visual language and high-fidelity prototyping.
*   **[Lab 6: Testing & Quality](lab6/README.md)** - Usability testing, card sorting, and GOMS/KLM analysis.
