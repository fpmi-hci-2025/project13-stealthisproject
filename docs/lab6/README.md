# Лабораторная работа №6: Тестирование и оценка качества прототипа

**Цель:** Изучить методы быстрой оценки концепций применительно к разработке пользовательского интерфейса приложения, провести оценку разработанного интерактивного прототипа и получить практические навыки по проведению usability-тестирования.

## Содержание отчета

### 1. Usability-тестирование
[Перейти к отчету (Этап 1)](01_usability_testing.md)
*   **Сценарии:** Поиск, Бронирование, Личный кабинет.
*   **Метрики:** Время выполнения, Количество ошибок, Успешность.
*   **Результат:** SUS Score = 78 (Хорошо).

### 2. Тестирование информационной архитектуры
[Перейти к отчету (Этап 2)](02_card_sorting.md)
*   **Метод:** Обратная карточная сортировка (Tree Testing).
*   **Результаты:** Структура "Профиль" и "Информация" понятна на 90%. Выявлена проблема с поиском функционала возврата билетов (размытие между "Архивом" и "Активными").

### 3. Тестирование ожиданий
[Перейти к отчету (Этап 3)](03_expectation_testing.md)
*   **Объекты:** Иконки уведомлений, Кнопки действия, Логотип.
*   **Вывод:** Ментальные модели пользователей совпадают с реализацией, за исключением деструктивного действия при клике на логотип во время чекаута.

### 4. Оценка по контрольным спискам (Checklists)
[Перейти к отчету (Этап 4)](04_checklists.md)
*   **Web:** 4.5/5. Проблемы с сохранением состояния фильтров.
*   **Mobile:** 4.8/5. Проблемы с отступами в футере.

### 5. Количественный анализ (GOMS и KLM)
[Перейти к отчету (Этап 5)](05_goms_klm.md)
*   **GOMS (Desktop):** Ввод данных с клавиатуры (Tab-навигация) эффективнее мыши на 40% (7.7 сек против 12.9 сек для логина).
*   **KLM (Mobile):** Использование нативных контролов (дейтпикеры) сокращает время ввода даты в 3 раза по сравнению с ручным набором.

## Общие выводы и рекомендации
Прототип системы соответствует критериям качества и готов к передаче в разработку с учетом следующих правок:
1.  Добавить маску ввода для паспортных данных.
2.  Реализовать предупреждение (confirmation dialog) при попытке уйти со страницы оформления заказа.
3.  Обеспечить корректную работу `tabindex` во всех формах.
4.  В мобильной версии увеличить кликабельные зоны ссылок в футере.
