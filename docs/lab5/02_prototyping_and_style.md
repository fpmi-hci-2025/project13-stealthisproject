## 3. Руководство по стилю (Assignment 3)

### 3.1. Style Guide
**Ссылка:** [Style Guide в Figma](https://www.figma.com/design/LGXVlGBrom6HTC565OfkU1/%D0%9F%D0%A7%D0%9C%D0%98?node-id=2368-52)

**Анализ выполнения:**
Создано руководство по стилям (UI Kit / Style Guide), обеспечивающее консистентность дизайна.

**Состав Style Guide:**
1.  **Цветовая палитра (Colors):**
    *   Primary: Синие оттенки (основное действие, бренд).
    *   Secondary: Дополнительные цвета для акцентов.
    *   Neutrals: Серые оттенки для текста, фонов и границ.
    *   System: Цвета статусов (Success - зеленый, Error - красный, Warning - желтый).

2.  **Типографика (Typography):**
    *   Определены стили заголовков (H1, H2, H3...) и основного текста (Body, Caption).
    *   Указаны гарнитура, размеры, интерлиньяж и начертания.

3.  **Элементы интерфейса (Components):**
    *   **Кнопки (Buttons):** Определены размеры (Large, Medium, Small), состояния (Default, Hover, Pressed, Disabled) и варианты (Primary, Secondary, Text).
    *   **Поля ввода (Inputs):** Состояния (Default, Focus, Error, Disabled), наличие плейсхолдеров и меток.
    *   **Иконки (Icons):** Набор системных иконок в едином стиле.
    *   **Сетка (Grid):** Описание модульной сетки для выравнивания контента.

**Вывод:**
Представленные артефакты (Sitemap, Wireframes, Design, Style Guide) полностью покрывают требования к этапам проектирования и стандартизации интерфейса. Разделение на этапы (от структуры к визуалу) соблюдено, наличие Style Guide гарантирует масштабируемость и поддержку проекта.
