## 2. Спецификация конечных точек API (Endpoints)

| Актор | Use Case (Вариант использования) | Маршрут (Endpoint) | HTTP-метод | Аутентификация |

| **Пассажир** | **UC-1.2** Обновление профиля | `/users/me` | `PUT` | Да |
| **Пассажир**, **Кассир** | **UC-3** Поиск рейса (список) | `/routes/search` | `GET` | Нет |
| **Пассажир** | **UC-4** Просмотр деталей рейса | `/routes/{id}` | `GET` | Нет |
| **Пассажир** | **UC-5** Просмотр схемы мест вагона | `/trains/{id}/seats` | `GET` | Нет |
| **Пассажир** | **UC-6** Оформление заказа (билета) | `/orders` | `POST` | Да |
| **Пассажир** | **UC-7** Оплата заказа | `/orders/{id}/pay` | `POST` | Да |
| **Пассажир** | **UC-8** Просмотр истории поездок | `/orders` | `GET` | Да |

| **Администратор** | **UC-9** Изменить рейс/расписание | `/routes/{id}` | `PUT` | Да (Admin) |
| **Администратор** | **UC-9** Удалить рейс | `/routes/{id}` | `DELETE` | Да (Admin) |
