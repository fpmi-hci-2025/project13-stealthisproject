# 5. Разработать объектную модель

Объектная модель позволяет понять интерфейс через объекты ментальной модели пользователя и систематизировать все объекты продукта.

## 5.1. Информационные объекты (Объекты-данные)

### 1. User (Пользователь)
- **Мощность:** Тысячи (10,000+)
- **Представления:** Профиль пользователя, Иконка в хедере, Форма входа/регистрации
- **Действия:** Регистрация, Вход, Выход, Обновление профиля, Сброс пароля
- **Атрибуты:** ID, Email, Хэш пароля, Телефон, Имя, Фамилия, Дата регистрации, Роль

### 2. Passenger (Пассажир)
- **Мощность:** Десятки тысяч (каждый пользователь может иметь несколько)
- **Представления:** Карточка пассажира, Строка в списке, Форма добавления/редактирования
- **Действия:** Добавить, Обновить, Удалить, Просмотреть инфо
- **Атрибуты:** ID, ID пользователя, Паспортные данные, ФИО, Дата рождения, Гражданство

### 3. Station (Станция)
- **Мощность:** Сотни (100-500)
- **Представления:** Точка на карте, Строка в выпадающем списке, Название в билете
- **Действия:** Добавить, Обновить, Просмотреть инфо
- **Атрибуты:** ID, Название, Код, Город, Адрес, Координаты

### 4. Route (Маршрут)
- **Мощность:** Десятки (50-100)
- **Представления:** Линия на карте, Карточка маршрута в расписании, Детальный вид
- **Действия:** Добавить, Обновить, Удалить, Просмотреть инфо
- **Атрибуты:** ID, Номер, Станция отправления, Станция прибытия, Время в пути

### 5. Train (Поезд)
- **Мощность:** Сотни (активных рейсов)
- **Представления:** Карточка поезда в поиске, Детальная информация, Схема состава
- **Действия:** Добавить, Обновить, Отменить, Просмотреть инфо
- **Атрибуты:** ID, Номер, Тип, Маршрут, Дата отправления, Статус

### 6. Carriage (Вагон)
- **Мощность:** Тысячи (в составе поездов)
- **Представления:** Схема вагона, Вкладка выбора вагона
- **Действия:** Добавить, Обновить, Просмотреть места
- **Атрибуты:** ID, Номер, Тип, Всего мест, Свободных мест

### 7. Seat (Место)
- **Мощность:** Десятки тысяч
- **Представления:** Квадратик на схеме (занят/свободен), Номер в билете
- **Действия:** Забронировать, Освободить, Просмотреть инфо
- **Атрибуты:** ID, Номер, Тип (верх/низ), Цена, Доступность

### 8. Order (Заказ)
- **Мощность:** Тысячи (постоянно растет)
- **Представления:** История заказов, Страница подтверждения, Чек
- **Действия:** Создать, Оплатить, Отменить, Вернуть
- **Атрибуты:** ID, Пользователь, Дата, Статус, Сумма, Способ оплаты

### 9. Ticket (Билет)
- **Мощность:** Тысячи
- **Представления:** PDF-файл, QR-код на экране, Карточка в "Моих поездках"
- **Действия:** Скачать, Показать QR, Вернуть
- **Атрибуты:** ID, Пассажир, Поезд, Место, Цена, Номер билета, Статус

## 5.2. Функциональные объекты

### 1. SearchQuery (Поиск рейса)
- **Мощность:** Единицы (активный контекст поиска)
- **Представления:** Панель поиска (виджет), Страница результатов, Панель фильтров
- **Действия:** Искать, Применить фильтры, Сортировать
- **Атрибуты:** Откуда, Куда, Дата, Кол-во пассажиров, Тип вагона

## 5.3. Связи между объектами
- **User → Passenger (1:N):** Пользователь управляет списком пассажиров.
- **User → Order (1:N):** Пользователь создает историю заказов.
- **Order → Ticket (1:N):** Один заказ может содержать билеты для нескольких пассажиров.
- **Train → Route (N:1):** Поезд следует по конкретному маршруту.
- **Train → Carriage (1:N):** Поезд состоит из вагонов.
- **Carriage → Seat (1:N):** Вагон содержит места.
- **Ticket → Seat (1:1):** Билет закрепляет конкретное место.
