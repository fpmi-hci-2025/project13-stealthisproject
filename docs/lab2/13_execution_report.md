# 13. Отчет о выполнении лабораторной работы №2

**Тема:** Проектирование концептуальной модели и интерфейса системы электронных билетов.
**Цель:** Разработать детальную концепцию взаимодействия пользователей с системой, включая информационную архитектуру, навигацию и визуальные макеты.

## 13.1. Планирование этапа концептуального проектирования

Процесс проектирования был разбит на следующие этапы:

1.  **Анализ требований и пользователей:**
    *   Изучение результатов Лабораторной работы №1.
    *   Уточнение профилей пользователей и их задач.
    *   Формирование объектной модели системы.

2.  **Информационная архитектура:**
    *   Определение типа интерфейса (Гибридный: WIMP + Touch).
    *   Проведение карточной сортировки для группировки функций.
    *   Разработка карты сайта и структуры меню.

3.  **Моделирование взаимодействия:**
    *   Создание навигационных моделей для каждого персонажа.
    *   Разработка Customer Journey Map (CJM) для выявления точек контакта и эмоций.
    *   Построение Карты влияния (Impact Map) для связи бизнес-целей с функциями.

4.  **Визуализация и прототипирование:**
    *   Создание концептуальных макетов (Wireframes).
    *   Разработка интерактивных раскадровок (сценариев).
    *   Подготовка дизайн-макетов с использованием модульных сеток.

## 13.2. Краткое описание выполненных шагов

В ходе работы были созданы следующие документы и артефакты:

1.  **Постановка задачи и Стратегия дизайна** (`01_problem_statement.md`, `02_design_strategy.md`)
    *   Определены ключевые сценарии и визуальный стиль (минимализм, синий цвет).
    
2.  **Профили и Задачи** (`03_group_profile.md`, `04_user_tasks_roles.md`)
    *   Детализированы роли: Пассажир (Частый/Редкий), Кассир, Администратор.
    
3.  **Объектная модель** (`05_object_model.md`)
    *   Выделены информационные (Билет, Поезд) и функциональные (Поиск) объекты.
    
4.  **Информационная архитектура** (`06_information_architecture.md`)
    *   Разработана структура меню и карта сайта.
    *   Составлен глоссарий терминов.
    
5.  **Концептуальные макеты** (`07_conceptual_mockups.md`)
    *   Описаны wireframes для веб и мобильной версии.
    *   Построена схема навигации (Wireflow).
    
6.  **Навигационная модель** (`08_navigation_model.md`)
    *   Построены диаграммы состояний для каждого персонажа.
    *   Создана общая диаграмма путей системы.
    
7.  **CJM и Impact Map** (`09_cjm_impact_map.md`)
    *   Карта влияния связала цель "Рост онлайн-продаж" с функциями.
    *   CJM разработаны для всех 4-х персонажей (Анна, Владимир, Ольга, Дмитрий).
    
8.  **Интерактивные раскадровки** (`10_interactive_storyboards.md`)
    *   Описаны пошаговые сценарии использования.
    *   Составлена совокупная диаграмма взаимодействия (успех + ошибки).
    
9.  **Дизайн-макеты** (`11_design_mockups.md`)
    *   Определены сетки: 12-колоночная для Web (1440px) и мобильная (375px).
    *   Описана структура ключевых экранов.

## 13.3. Заключение

В результате выполнения работы спроектирован полный пакет документации для разработки интерфейса системы. Концептуальная модель покрывает потребности всех групп пользователей и соответствует бизнес-целям проекта.
