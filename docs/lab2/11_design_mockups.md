# 11. Дизайн-макеты

В данном разделе представлено описание дизайн-макетов для веб-приложения и мобильного приложения, разработанных с использованием модульных сеток.

## 11.1. Сетки и разрешения

### Веб-приложение
*   **Разрешение:** 1440px (Desktop)
*   **Сетка:** 12-колоночная (Bootstrap style)
*   **Ширина контента:** 1170px
*   **Колонки:** 70px
*   **Отступы (Gutter):** 30px
*   **Поля (Margins):** Автоматические (по центру)

### Мобильное приложение
*   **Разрешение:** 375x812px (iPhone X/11/12/13 mini)
*   **Сетка:** 4-колоночная или 8pt grid
*   **Поля (Margins):** 16px или 20px
*   **Отступы (Gutter):** 16px

## 11.2. Макеты веб-приложения (1440px)

### 1. Главная страница (Home)
**Структура по сетке:**
*   **Header (12 колонок):** Логотип (2 кол), Меню (6 кол), Вход (2 кол). Высота 80px.
*   **Hero Block (12 колонок):** Фоновое фото на всю ширину.
    *   **Поисковый виджет (8 колонок, отступ 2 слева):** Белая плашка поверх фото. Внутри 4 поля в ряд (Откуда, Куда, Дата, Кнопка).
*   **Popular (12 колонок):** Заголовок по центру.
    *   **Карточки (3 карточки по 4 колонки):** Фото города, название, цена "от ...".

### 2. Результаты поиска (Search Results)
**Структура по сетке:**
*   **Filter Sidebar (3 колонки):** Фильтры по цене, времени, типу. Фон светло-серый.
*   **Results List (9 колонок):** Список карточек поездов.
    *   **Train Card (9 колонок):** Внутри карточки:
        *   Время (2 кол)
        *   Маршрут (3 кол)
        *   Тип вагона и цена (2 кол)
        *   Кнопка "Выбрать" (2 кол)

### 3. Выбор места (Seat Selection)
**Структура по сетке:**
*   **Carriage Info (12 колонок):** Информация о вагоне (номер, класс, удобства).
*   **Scheme (8 колонок):** Визуальная схема вагона. Места - интерактивные квадраты.
*   **Legend (4 колонки):** Легенда (свободно, занято, выбрано) и итоговая цена.

## 11.3. Макеты мобильного приложения (375px)

### 1. Главная (Home)
**Структура:**
*   **Header:** Логотип по центру.
*   **Search Form:** Вертикальный стек полей.
    *   Откуда (Full width)
    *   Куда (Full width)
    *   Дата (Full width)
    *   Кнопка "Найти" (Full width, высота 48-56px).
*   **Recent:** Горизонтальный скролл карточек недавних поисков.

### 2. Мой билет (Ticket)
**Структура:**
*   **Card:** Белая карточка на сером фоне.
    *   QR-код (200x200px по центру).
    *   Информация о рейсе (выравнивание по левому краю, отступ 16px).
*   **Actions:** Кнопки "Скачать" и "Wallet" внизу экрана (Fixed footer).

### 3. Профиль (Profile)
**Структура:**
*   **Avatar:** Круглое фото 80px по центру.
*   **Menu List:** Список пунктов (Мои заказы, Пассажиры, Настройки).
    *   Каждый пункт: Иконка (24px) + Текст + Стрелка (Chevron right).
    *   Разделители на всю ширину.

## 11.4. Цветовая схема (Style Guide)

*   **Primary Blue:** `#0066CC` (Кнопки, активные элементы)
*   **Success Green:** `#00AA44` (Подтверждения, свободные места)
*   **Text Dark:** `#333333` (Основной текст)
*   **Text Gray:** `#777777` (Второстепенный текст)
*   **Background:** `#F5F5F5` (Фон страниц)
*   **White:** `#FFFFFF` (Фон карточек)
