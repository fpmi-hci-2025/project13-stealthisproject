# 8. Навигационная модель системы

## 8.1. Навигационные модели персонажей

### 1. Анна Петрова (Частый пассажир)
**Цель:** Купить билет за минимальное время, используя сохраненные данные.

```mermaid
stateDiagram-v2
    [*] --> Главная
    Главная --> Авторизация: Вход
    Авторизация --> Главная: Успешно
    Главная --> СохраненныйМаршрут: Клик по "Минск-Гомель"
    СохраненныйМаршрут --> ВыборПоезда: Список рейсов
    ВыборПоезда --> Оплата: Выбор (данные автозаполнены)
    Оплата --> Билет: Оплата в 1 клик
    Билет --> [*]: Скачать/Показать QR
```

### 2. Владимир Иванович (Редкий пассажир)
**Цель:** Найти рейс и купить билет, внимательно проверяя каждый шаг.

```mermaid
stateDiagram-v2
    [*] --> Главная
    Главная --> Поиск: Ввод станций и даты
    Поиск --> Результаты: Найти
    Результаты --> ДеталиПоезда: Выбор поезда
    ДеталиПоезда --> СхемаВагона: Выбор вагона
    СхемаВагона --> ВводДанных: Выбор места
    ВводДанных --> Проверка: Ввод паспорта
    Проверка --> Оплата: Данные верны
    Оплата --> Билет: Успешная оплата
    Билет --> [*]: Печать билета
```

### 3. Ольга Сергеевна (Кассир)
**Цель:** Быстро оформить билет для клиента в очереди.

```mermaid
stateDiagram-v2
    [*] --> РабочийСтол
    РабочийСтол --> ПоискРейса: Запрос клиента
    ПоискРейса --> ВыборМеста: Быстрый выбор
    ВыборМеста --> ФормаПассажира: Ввод данных
    ФормаПассажира --> Оплата: Подтверждение
    Оплата --> Печать: Прием наличных/карты
    Печать --> РабочийСтол: Следующий клиент
```

### 4. Дмитрий Александрович (Администратор)
**Цель:** Добавить новый рейс в расписание.

```mermaid
stateDiagram-v2
    [*] --> Дашборд
    Дашборд --> УправлениеРейсами: Переход в раздел
    УправлениеРейсами --> СозданиеРейса: Кнопка "Добавить"
    СозданиеРейса --> НастройкаМаршрута: Выбор станций
    НастройкаМаршрута --> НастройкаСостава: Добавление вагонов
    НастройкаСостава --> Публикация: Сохранить
    Публикация --> Дашборд: Рейс активен
```

## 8.2. Общая диаграмма путей (General Path Diagram)

Диаграмма объединяет все основные потоки пользователей в единую систему навигации.

```mermaid
graph TD
    %% Nodes
    Start((Старт))
    Home[Главная страница]
    Login[Авторизация / Регистрация]
    Profile[Личный кабинет]
    Search[Поиск рейсов]
    Results[Результаты поиска]
    Details[Детали поезда / Вагоны]
    Seat[Выбор места]
    Passenger[Ввод данных пассажира]
    Payment[Оплата]
    Ticket[Билет / Заказ]
    Admin[Админ-панель]
    ManageRoutes[Управление рейсами]
    ManageOrders[Управление заказами]

    %% Edges
    Start --> Home
    Home --> Login
    Home --> Search
    Home --> Profile
    
    Login --> Home
    Login --> Admin: Если роль = Админ
    
    Admin --> ManageRoutes
    Admin --> ManageOrders
    
    Profile --> Ticket: История поездок
    
    Search --> Results
    Results --> Details
    Details --> Seat
    Seat --> Passenger
    
    Passenger --> Payment
    Payment --> Ticket
    
    Ticket --> Home: На главную
    Ticket --> Profile: В историю
```
