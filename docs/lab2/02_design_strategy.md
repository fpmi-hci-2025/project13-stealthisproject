# 2. Стратегия дизайна

## Общая концепция
**Философия:** Минимализм + функциональность
**Принцип:** "Меньше кликов - больше результата"
**Подход:** Mobile-first, адаптивный дизайн

## Дизайн для разных персонажей

### Для Анны (частый пассажир)
- **Приоритет:** Скорость
- **Решение:**
  - Сохраненные маршруты на главном экране
  - Автозаполнение данных
  - Оплата в один клик
  - Минимум шагов (цель: 3-4 экрана)

### Для Владимира Ивановича (редкий пассажир)
- **Приоритет:** Понятность
- **Решение:**
  - Крупный шрифт (минимум 16px)
  - Подсказки на каждом шаге
  - Прогресс-бар оформления
  - Возможность распечатать билет

### Для Ольги Сергеевны (кассир)
- **Приоритет:** Эффективность
- **Решение:**
  - Горячие клавиши
  - Быстрый поиск (автокомплит)
  - Минимум кликов
  - Четкая визуализация

### Для Дмитрия Александровича (администратор)
- **Приоритет:** Контроль
- **Решение:**
  - Дашборд с аналитикой
  - Гибкие фильтры
  - Экспорт данных
  - Массовые операции

## Визуальный язык
**Цветовая палитра:**
- Основной: Синий (#0066CC) - доверие, надежность
- Акцент: Зеленый (#00AA44) - успех, доступность
- Предупреждение: Оранжевый (#FF9900)
- Ошибка: Красный (#DD0000)
- Фон: Светло-серый (#F5F5F5)

**Типографика:**
- Заголовки: Inter Bold, 24-32px
- Основной текст: Inter Regular, 16px
