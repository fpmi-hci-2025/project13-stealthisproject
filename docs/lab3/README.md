## Как просматривать диаграммы

Файлы спецификаций содержат встроенный код на языке **PlantUML**.
Для корректного отображения диаграмм рекомендуется:
1.  Установить плагин **PlantUML** для вашей IDE (VS Code, IntelliJ).
2.  Или установить расширение для браузера **PlantUML Viewer**.
3.  Или скопировать код диаграммы на сайт [PlantText.com](https://www.planttext.com/).
