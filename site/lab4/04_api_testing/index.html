Лабораторная работа №4. Задание 4: Проектирование и тестирование API

1. Спецификация OpenAPI

Разработана полная спецификация API в формате OpenAPI 3.0 (Swagger). Файл содержит описание всех маршрутов, схем данных и параметров запросов.

Скачать файл спецификации (openapi.yaml)

Для просмотра и тестирования API рекомендуется использовать онлайн-редактор Swagger Editor, куда можно импортировать содержимое файла openapi.yaml.

2. Примеры запросов и ответов

Ниже приведены тела запросов (Request Body) и возможные коды ответов для основных операций изменения данных (POST, PUT).

2.1. Регистрация (POST /auth/register)

Тело запроса: 

{
  "email": "ivan.petrov@example.com",
  "password": "securePassword123!",
  "firstName": "Иван",
  "lastName": "Петров"
}

Коды ответов: * 201 Created — Учетная запись успешно создана. * 400 Bad Request — Ошибка валидации (например, некорректный email или слишком короткий пароль).

2.2. Вход в систему (POST /auth/login)

Тело запроса: 

{
  "email": "ivan.petrov@example.com",
  "password": "securePassword123!"
}

Коды ответов: * 200 OK — Успешный вход, возвращен JWT токен. * 401 Unauthorized — Неверные учетные данные.

2.3. Создание заказа (POST /orders)

Тело запроса: 

{
  "routeId": 105,
  "seatId": 45,
  "passengerId": null
}

Коды ответов: * 201 Created — Заказ успешно создан в статусе PENDING. * 400 Bad Request — Место уже занято или рейс не найден. * 401 Unauthorized — Пользователь не авторизован.

2.4. Оплата заказа (POST /orders/{id}/pay)

Тело запроса: 

{
  "cardNumber": "4276123456789012",
  "expiryDate": "12/26",
  "cvv": "123"
}

Коды ответов: * 200 OK — Оплата прошла успешно. * 400 Bad Request — Ошибка данных карты или недостаточно средств. * 404 Not Found — Заказ не найден.

3. Статусы HTTP-ответов

В API используются стандартные коды состояния HTTP для индикации результатов операций:

Код Статус Описание в контексте API
200 OK Запрос выполнен успешно (для GET, PUT, POST).
201 Created Ресурс успешно создан (для POST: регистрация, заказ).
400 Bad Request Ошибка валидации входных данных клиента.
401 Unauthorized Отсутствует или неверен токен аутентификации.
403 Forbidden Недостаточно прав (например, пассажир пытается удалить рейс).
404 Not Found Запрашиваемый ресурс (рейс, заказ, пользователь) не найден.
500 Internal Server Error Внутренняя ошибка сервера.
