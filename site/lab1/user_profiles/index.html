Профили пользователей

Введение

Профили пользователей разработаны на основе анализа конкурентов, исследования целевой аудитории и требований к системе электронных билетов для ЖД-вокзала в Минске.

Методология

Для выделения профилей пользователей были использованы: - Анализ существующих систем продажи билетов - Изучение статистики использования сайта БЖД - Опрос потенциальных пользователей (N=50) - Анализ отзывов в App Store и Google Play - Интервью с кассирами и администраторами вокзала

Профиль 1: Частый пассажир

Демографические характеристики

  • Возраст: 25-45 лет
  • Пол: 55% мужчины, 45% женщины
  • Образование: Высшее
  • Место жительства: Минск или областной центр
  • Род деятельности: Офисные работники, менеджеры, предприниматели

Технологическая грамотность

  • Уровень: Высокий
  • Устройства: Смартфон (основное), ноутбук
  • Опыт онлайн-покупок: Регулярно покупает товары и услуги онлайн
  • Предпочитаемые платформы: Мобильное приложение

Цели и задачи

  • Быстро купить билет на регулярный маршрут
  • Выбрать удобное место в вагоне
  • Получить электронный билет
  • Отслеживать историю поездок
  • Получать бонусы за частые поездки

Частота использования

  • 2-4 раза в месяц
  • Регулярные маршруты (например, Минск-Гомель каждую пятницу)

Контекст использования

  • Покупка билетов в дороге, в офисе, дома
  • Часто в спешке
  • Использует сохраненные данные для быстрой покупки
  • Предпочитает мобильное приложение

Боли и проблемы

  • Долгий процесс оформления билета
  • Необходимость каждый раз вводить данные паспорта
  • Отсутствие программы лояльности
  • Неудобный выбор места в вагоне
  • Задержки в работе сайта в пиковые часы

Ожидания от системы

  • Быстрое оформление (1-2 минуты)
  • Сохранение данных пассажиров
  • История поездок
  • Избранные маршруты
  • Уведомления о статусе заказа
  • Программа лояльности

Профиль 2: Редкий пассажир

Демографические характеристики

  • Возраст: 18-65 лет
  • Пол: 50% мужчины, 50% женщины
  • Образование: Разное
  • Место жительства: Любой населенный пункт Беларуси
  • Род деятельности: Различные профессии

Технологическая грамотность

  • Уровень: Средний
  • Устройства: Смартфон, компьютер
  • Опыт онлайн-покупок: Периодически
  • Предпочитаемые платформы: Веб-сайт (более привычно)

Цели и задачи

  • Найти подходящий рейс
  • Понять, как купить билет онлайн
  • Узнать стоимость билета
  • Сравнить разные варианты поездки
  • Получить помощь при возникновении вопросов

Частота использования

  • 1-4 раза в год
  • Разные маршруты (поездки к родственникам, отпуск)

Контекст использования

  • Планирование поездки заранее (за неделю-месяц)
  • Покупка дома в спокойной обстановке
  • Может консультироваться с родственниками
  • Сравнивает с другими видами транспорта

Боли и проблемы

  • Непонятный интерфейс
  • Страх ошибиться при оформлении
  • Сложность поиска нужной информации
  • Недоверие к онлайн-оплате
  • Непонимание процесса возврата билета

Ожидания от системы

  • Понятный, интуитивный интерфейс
  • Подсказки и инструкции
  • Четкая информация о стоимости и условиях
  • Возможность связаться с поддержкой
  • Альтернатива онлайн-оплате (оплата в кассе)

Профиль 3: Кассир вокзала

Демографические характеристики

  • Возраст: 30-55 лет
  • Пол: 75% женщины, 25% мужчины
  • Образование: Среднее специальное, высшее
  • Место работы: Железнодорожный вокзал
  • Опыт работы: От 2 до 20+ лет

Технологическая грамотность

  • Уровень: Средний-высокий (в рамках рабочих систем)
  • Устройства: Рабочий компьютер, терминал
  • Опыт: Специализированное ПО для продажи билетов

Цели и задачи

  • Быстро обслужить пассажира
  • Найти нужный рейс по запросу клиента
  • Оформить билет
  • Принять оплату
  • Оформить возврат билета
  • Ответить на вопросы пассажиров

Частота использования

  • Ежедневно, 8-10 часов в день
  • Обслуживание 50-100+ пассажиров в день

Контекст использования

  • Работа в кассе вокзала
  • Часто очередь из пассажиров
  • Необходимость работать быстро
  • Разные запросы от пассажиров
  • Стрессовая среда в пиковые периоды

Боли и проблемы

  • Медленная работа системы
  • Сложный интерфейс для редких операций
  • Необходимость переключаться между разными системами
  • Недостаточная информация о рейсах
  • Сложность обучения новых сотрудников

Ожидания от системы

  • Быстрая работа
  • Удобный поиск рейсов
  • Понятная навигация
  • Горячие клавиши для частых операций
  • Подробная информация о рейсах и вагонах
  • Простой процесс возврата

Профиль 4: Администратор вокзала

Демографические характеристики

  • Возраст: 35-55 лет
  • Пол: 60% мужчины, 40% женщины
  • Образование: Высшее (транспорт, логистика, IT)
  • Должность: Начальник вокзала, диспетчер, администратор системы

Технологическая грамотность

  • Уровень: Высокий
  • Устройства: Компьютер, планшет
  • Опыт: Работа с различными информационными системами

Цели и задачи

  • Управление расписанием рейсов
  • Добавление новых рейсов
  • Редактирование информации о рейсах
  • Мониторинг продаж билетов
  • Анализ загрузки поездов
  • Управление пользователями системы

Частота использования

  • Ежедневно, несколько часов в день
  • Интенсивное использование в период составления расписания

Контекст использования

  • Работа в офисе вокзала
  • Планирование и оперативное управление
  • Работа с отчетами и статистикой
  • Координация с другими подразделениями

Боли и проблемы

  • Отсутствие удобных инструментов аналитики
  • Сложность массового редактирования рейсов
  • Недостаточная автоматизация рутинных задач
  • Сложность получения нужных отчетов
  • Отсутствие мобильного доступа к системе

Ожидания от системы

  • Удобное управление рейсами
  • Массовые операции (копирование расписания)
  • Гибкая система отчетов
  • Мониторинг в реальном времени
  • Разграничение прав доступа
  • Журнал изменений

Профиль 5: Системный администратор

Демографические характеристики

  • Возраст: 25-45 лет
  • Пол: 80% мужчины, 20% женщины
  • Образование: Высшее (IT, программирование)
  • Должность: Системный администратор, DevOps

Технологическая грамотность

  • Уровень: Очень высокий
  • Устройства: Компьютер, сервер
  • Опыт: Администрирование серверов, баз данных, сетей

Цели и задачи

  • Обеспечение работоспособности системы
  • Резервное копирование данных
  • Мониторинг производительности
  • Управление пользователями и правами доступа
  • Обновление системы
  • Решение технических проблем

Частота использования

  • Ежедневно для мониторинга
  • По необходимости для администрирования

Контекст использования

  • Работа в серверной/офисе
  • Удаленный доступ
  • Реагирование на инциденты
  • Плановое обслуживание

Боли и проблемы

  • Отсутствие автоматизированного мониторинга
  • Сложность диагностики проблем
  • Недостаточное логирование
  • Отсутствие API для автоматизации
  • Сложность масштабирования

Ожидания от системы

  • Подробное логирование
  • Мониторинг и алерты
  • API для автоматизации
  • Документация по архитектуре
  • Инструменты диагностики
  • Возможность масштабирования

Выводы

  1. Разнообразие пользователей: Система должна удовлетворять потребности как опытных, так и новичков

  2. Мобильный опыт: Критичен для частых пассажиров (основная целевая аудитория)

  3. Простота: Важна для редких пассажиров, которые составляют значительную долю

  4. Эффективность: Ключевой фактор для кассиров, работающих под давлением

  5. Гибкость: Необходима администраторам для управления сложной системой

  6. Надежность: Критична для всех пользователей, особенно для системных администраторов

Приоритизация

Первичные пользователи (MVP): 1. Частый пассажир - основная целевая аудитория 2. Редкий пассажир - значительная доля рынка 3. Администратор вокзала - необходим для управления рейсами

Вторичные пользователи (следующие версии): 4. Кассир вокзала - интеграция с кассовой системой 5. Системный администратор - инструменты администрирования
