# 4. Проанализировать задачи и роли пользователей

## Роли пользователей
1. **Частый пассажир (Анна)**: Ценит время, использует мобильное приложение, сохраняет данные.
2. **Редкий пассажир (Владимир Иванович)**: Нуждается в помощи, использует веб-сайт, ценит понятность.
3. **Кассир (Ольга Сергеевна)**: Работает быстро, использует десктоп, нуждается в горячих клавишах.
4. **Администратор (Дмитрий Александрович)**: Управляет системой, анализирует данные, использует десктоп.

## Ключевые задачи по ролям
- **Пассажир:** Поиск рейса -> Выбор поезда -> Выбор вагона/места -> Ввод данных -> Оплата -> Получение билета.
- **Кассир:** Поиск по запросу клиента -> Выбор места -> Ввод паспортных данных -> Оформление -> Печать.
- **Администратор:** Создание маршрута -> Добавление поезда -> Настройка цен -> Мониторинг продаж.
